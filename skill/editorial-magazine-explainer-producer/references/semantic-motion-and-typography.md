# 语义组件、节奏与文字合同

## 从句子提取关系

每个镜头回答六件事：

1. 谁或什么是主语；
2. 主语做了什么；
3. 谁/什么受到作用；
4. 哪里发生转折；
5. 最终状态是什么；
6. 观众此刻必须理解什么。

动画至少显示一种可理解关系：连接/断开、插入/拔出、替换/失效、传递/阻断、积累/泄漏、压缩/过载、比较/分类、反馈/无反馈、碰撞/包围、施压/释放、进入门槛/获得准入。

只摆名词标签不是语义动画。

## 独立组件边界

人物、工具、路径、受力对象、结果状态只要时间、方向、深度或作用方式不同，就必须独立寻址。生图负责成熟美术组件和构图参考，不负责把关系提前烤死。

完整构图只允许：

- 作为美术/构图参考；
- 作为真正的整幅情境插画；
- 作为 Flow 的无字准备态参考。

整图缩放、平移、裁切、视差或呼吸都不算组件语义动画。

几何图形只用于箭头、路径、遮罩、边界、聚光和次级强调；不能替代本该具象化的人物、门槛、岗位、工具或结果。

## 六阶段生命周期

每个主要层记录：

`enter → settle → act_or_receive → yield → resolve → exit`

- `enter`：从哪里、以何种逻辑进入；
- `settle`：观众何时能完整辨认；
- `act_or_receive`：对谁做什么或受到什么；
- `yield`：何时开始让位；
- `resolve`：当前关系的结论状态；
- `exit`：如何完全退出、变形成下一对象或降级到不抢焦。

透明度降到 60% 但仍明显可辨，不算退出。新主层进入后旧层仍围在周围，即接管失败。

## 三套时间

- `sceneStart`：镜头边界；
- `actionCue`：核心语义动作开始；
- `textCue`：解释文字开始。

第一阶段不得自动绑定 `sceneStart`。铺垫词期间只显示中性上下文。动作准备最多比真实关键词提前约 0.10–0.18 秒；不得提前揭示结论。文字既不能抢拍，也不能等动作已经完成后才出现。

口播顺序改变时重排阶段，不得只把错误动画整体后移。

## 节奏感知预算

观众需要时间完成“看见主体—读懂解释—理解关系”。

- 一个稳定主构图默认约 2–5 秒。
- 低于 1.5 秒的完整主构图必须写例外理由；否则合并到相邻主构图，用内部聚焦表达。
- 核心动作完成后，在口播允许时至少保留约 0.8 秒可辨认状态。
- 字幕切换、语气词和并列小项不自动触发整套场景替换。
- 多个同类项优先在一套构图里依次聚焦，例如“五类目的”“三个现实验证步骤”。
- 每 15 秒审计一次主构图切换密度；开头和信息密集段必须人工连续观看。
- 节奏优化可以减少主阶段数量，但必须保留核心语义动作。

连续两个主构图都短于 1.5 秒、主体刚落稳就被替换、解释尚未读清就退出，均为阻断问题。

## 三种文字职责

| 文字层 | 职责 | 禁止 |
|---|---|---|
| 字幕 | 准确呈现批准 SRT 原话 | 擅改、断词、机械换行 |
| 字幕高亮 | 抓住当句一个完整关键词或短语 | 随机三四字、半个词 |
| 解释文字 | 提供判断、分类、因果、关系或结论 | 换几个字复述字幕 |

对象标签只负责识别物件状态，不承担第二套字幕。

判断解释文字是否合格：遮住字幕后，解释文字仍应告诉观众“这组动画证明/分类/判断了什么”；若只是重复口播名词，就重写。

## 解释文字形式

按语义轮换：

- 无底板叠字；
- 侧边竖排；
- 左右关系字；
- 括号批注；
- 结论印章；
- 阶梯递进；
- 弧线引导；
- 报刊短栏；
- 聚焦环；
- 局部揭示；
- 票签；
- 路径标识。

只换外框而固定为同一顶部横卡，不算形式变化。独立解释文字不无理由附着运动物件；但如果文字属于手机屏幕、气泡、票据、图表、按钮等语义容器，它必须成为父组件的一部分并同步运动。前一解释完全退出后下一解释才接管。

## 语义容器

对气泡、票据、手机屏幕、图表、网页、名单、文档、输入框、按钮、选项、目的槽、反馈卡和标签逐一标记：

- `communicative`：承担交流、选择、判断或提示，必须有本地可读文字；
- `decorative`：纯装饰，必须在镜头合同中声明，不得形成“应该有字”的强烈版式暗示。

生图/Flow 只生成无字容器和动作，本地排版添加中文。任何承担语义的空白容器都判失败。

### 组件内原生文字合同

本地补字不是“在画面上方再放一张卡”，而是把文字写回组件内部。每个 `communicative` 容器必须记录：

- `parent_layer_id`：文字属于哪个真实组件；
- `coordinate_space=parent_local`：使用父组件本地坐标，不用整片绝对坐标硬贴；
- `text_region_normalized`：容器内部归一化可写区域，`x/y/width/height` 均在 0–1 内；
- `padding_percent`：默认可从 4%–10%起步，依真实边框和留白微调；
- `perspective_mode=matched_parent`、`clip_to_container=true`、`moves_with_parent=true`；
- `visual_hierarchy_role` 与 `minimum_font_px`：主信息、次信息、元数据分层，手机端最小信息字默认不低于约 32px。

执行顺序是：找内部空白/信息槽 → 确定可写矩形和内边距 → 在父组件本地坐标中排字 → 匹配透视/圆角/遮罩 → 绑定父组件运动 → 再把“组件＋内部文字”作为一个整体做逐镜构图适配。文字必须像手机界面、名单、图表或票据本身，不得漂在外面、穿过边框、父组件移动时脱节或用第二套字幕复述口播。

## 1080×1920 默认空间

- 顶部栏目/命题区：约 y=70–300；
- 解释文字弹性区：约 y=260–560；
- 核心组件区：约 y=520–1280；
- 字幕独占区：约 y=1305–1535；
- 平台安全区：y=1536–1919。

本地组件优先集中在画面中轴，关键主体与左右边缘至少保留约 72px 安全距离。正式可读性优化按资产类别分别执行：

- `silent_google_flow`：默认保持已批准画面尺寸、裁切、速度、动作顺序和绝对时间位置不变；只有用户单独批准后才能改变。
- `independent_component_animation`：完成组件内原生文字后，把完整视觉组相对批准基线以放大约 8%–12%为目标并向中部集中；逐镜可在约 4%–15%内微调。偏离目标需记录理由，超出微调范围需另获明确批准；禁止不看构图就全片统一缩放。
- `full_editorial_illustration`：只允许在原边框内部轻微放大约 4%–6%，不得裁掉边框、人物、道路、手部、关键道具或结果状态。若本轮已批准“整体放大”，保持 0% 或超出范围必须逐镜记录理由并获得批准。

本地组件默认硬安全边界为 `x=72–1008, y=300–1290`，优选核心舞台为 `x=96–984, y=380–1280`。主要轴填充比例以约 72%–90%为起点，最终宽度占画面不高于 90%，高度占画面不高于 92%，水平中心偏移默认不超过 90px。它们是帮助首轮落位的约束，不是统一变换参数；每镜仍须根据人物、手机、图表、路径、字幕和平台 UI 微调。

放大后逐镜记录：基线比例、最终比例、最终包围盒、主轴填充、中心偏移、左右/上下安全距离、裁切事件、漂移、构图破坏、字幕/解释文字遮挡和人工舒适度。裁切、漂移、构图破坏、主视觉遮挡和不舒适密度必须为 0。满足百分比但看不清、太挤、出画或重心失衡，仍判失败。

解释文字与字幕保持明显距离，目标约 390px。空间冲突时移动、缩放、让位或退出组件/解释层，不能删必要解释，也不能把字幕推到平台 UI 区。

## 字幕排版

- 竖屏短视频默认优先单行；不依赖浏览器自动换行。
- 逐条测量文本宽度，按长度动态字号或重新拆分 SRT；不得改变语义与时间对应。
- 二行字幕仅作为经批准的例外，并专门检查断句和纵向占位。
- 中文词组不得拆断；不得裁切、横向溢出、贴边。
- 字幕必须是画面中的高层级前景信息：先建立上一批准版逐条字号和位置基线，再确认本轮实际增量；在不溢出的前提下使用比普通说明文字更舒适的大字号，不得只达到历史绝对下限就宣称“已经放大”，也不得为了塞下一行把字号压小到失去观看舒适度。
- 字幕默认相对传统底部位置向中心安全区上移；偏移量由逐镜主视觉避让决定。不能把字幕推入平台 UI 区，也不能遮挡人物脸部、核心动作、结果状态或必要解释文字。
- 对比策略必须随背景稳定成立：优先使用与插画统一的深色实心字＋暖白粗描边＋纸片投影，或等价的双边缘/局部底衬方案。最终编码抽帧的最差背景对比度目标不低于 4.5:1；若难以可靠计算，必须使用不依赖单一背景明度的双边缘方案并完成人工最差帧审计。
- 字体、描边、投影和关键词色必须属于同一杂志插画视觉系统；高对比不能退化成与画面无关的通用短视频模板。
- 最终从编码 MP4 抽取最长至少 5 条字幕做单行边界总览。
- 最终还要抽取背景最复杂、主视觉最低、关键词最长和 Flow 低位主体镜头，检查字幕层级、对比、中心位移和主视觉避让。
- 已验证短片基线为最大宽度约 960px、49–54px 动态字号；这是起始参考，不替代实际测量，也不构成压小字幕的理由。

## 正式画面清洁

正式渲染前移除：镜号、SceneHeader、场景说明、生产备注、图层名、调试框、安全区示意、内部时间码和水印。审核图可以显示制作信息，但必须位于画外/说明区，不能成为将被复用的正式画面图层。

## 组件与文字一票否决

- 整图轻动冒充语义动画；
- 旧层未退出，新层持续叠加；
- 动作早于口播关键词 0.18 秒以上；
- 解释文字抢拍、漏掉或动作结束后才补；
- 全片主构图频繁闪切；
- 核心语义容器空白；
- 语义容器文字漂在组件外、没有父图层绑定、透视/遮罩不匹配，或父组件运动时文字不同步；
- 解释文字复述字幕或小到手机不可读；
- 全片只用一种卡片；
- 解释文字与字幕像两套字幕；
- 生成可读中文、乱码或生产标记进入正式片；
- 字幕自动换行、断词、裁切或贴边。
- 本地组件没有按逐镜安全构图放大和向中部集中；
- 把“整体放大”执行成全片统一缩放，造成出画、漂移、过密或主次关系破坏；
- Flow 在未授权情况下随本地组件一起缩放或裁切；
- 整幅插画越过原边框或裁掉关键对象；
- 字幕对比不足、视觉层级低、字号不舒适，或遮挡主视觉/解释文字。
