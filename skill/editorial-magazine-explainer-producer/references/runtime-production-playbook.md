# 运行时施工手册

## 先判断这条片值不值得进重产线

只有同时满足以下条件才进入完整杂志插画产线：

1. 选题已经由牧之确认；
2. 定稿文案、支撑证据和最终口播音频已经稳定；
3. 这条承担重点内容任务，值得投入差异化画面；
4. 杂志插画比露脸、白板、评论回应、数据名单或VOX更适合表达；
5. 用户知道会经过导演理解/完整故事板、全片有声动态分镜/最难段真实样片、完整低清粗剪和最终母版审核。

不满足时，退回总控台推荐标准片或快速片，不启动一整套机器合同。

## 一张施工单接住整个项目

`editorial-job-card.md` 是每轮唯一的运行入口；进入视觉生产后，项目根目录`design.md`是唯一视觉入口。施工单不重复写规则，只写本项目当前事实：

- 正在做哪一条；
- 真实口播、SRT、音频和已批准版本在哪里；
- 当前处于哪个 Gate；
- 哪些绝对不能动；
- 本轮只准改什么；
- 下一份可见交付是什么；
- 本轮只需打开哪一个参考文件；
- 上一次机器检查与人工观看是否通过；
- 需要牧之决定什么。

施工单与机器合同冲突时，以真实资产、批准记录和机器合同为准，并立即修正施工单。

任何生图、B-roll、关键帧、图生视频、原生组件或合成任务开始前，额外读取当前项目`design.md`及其`artifacts/design-lock.json`。部门提示词、供应商提示词和临时审美说明不得绕过或覆盖`design.md`。

## 重点片固定四次可见决策包

1. 导演理解＋完整视觉故事板：告诉牧之如何理解口播、每个可理解画面段采用什么表现路线、持续多久、怎样进入/解释/落稳/退出；不预设镜头数量；
2. 全片有声动态分镜＋15—20秒真实完成度样片：先验完整节奏、阅读和转场，再验正式画风、动作、文字、人声与本条新BGM；
3. 完整低清粗剪：从头到尾一次看完，不拿局部漂亮镜头掩盖整体问题；
4. 最终母版：粗剪通过后才高质量渲染，并附检查结论、回退版和最需要看的三个位置。

内部可以有多个 Gate，用户界面不要变成工程看板。

## 重复故障预渲染清单

以下问题在真实动态样片和完整低清粗剪前必须机器或抽帧检查，命中任何一项不得继续扩量或渲染：

- 语义容器空白，或文字漂在组件外；
- 解释文字只是换几个字复述字幕；
- 旧主层没有完整退出；
- 动作早于口播关键词；
- 主构图短于1.5秒却没有例外理由；
- 为凑镜头数量碎切，或故事板时间有缺口/重叠；
- 准确数据、学校名、名单、表格或政策正文走纯图生视频；
- 官方材料没有原始来源，或来源图表没有画面脚注；
- 图生视频短于对应口播却没有续接方案，靠慢放、停死、循环或静态闪图补时长；
- 没有完整有声动态分镜或本条新BGM就进入批量生产；
- 本条BGM命中任一历史项目的曲目身份、原始哈希或音频指纹，且没有用户明确沿用批准；
- 本地组件过小、统一缩放、裁边或重心漂移；
- Flow被误缩放、重裁切、调速或带入源声音；
- 字幕断词、自动换行、贴边、对比不足或遮住主视觉；
- 镜号、制作备注、安全框、乱码或水印进入正式画面；
- 只改局部却导致人声、字幕、时间线、Flow或配乐哈希漂移。
- 整体像PPT：依赖卡片轮播、顶部标题和整页切换，组件之间没有真实作用关系；
- 整体像廉价AI：人物、材质、透视、手部、伪文字或细节无来由地漂移；
- 画风混乱：不同镜头像来自不同模板或不同模型，无法与黄金基准归为同一条片；
- 缺少`design.md`或设计锁，生图与供应商靠文字临场重新猜人物、场景和画风；
- 动画僵硬：只有匀速缩放、平移、弹出，动作不受口播关键词和语义因果驱动。

同一错误在连续两个项目出现，必须为它新增自动检查或模板必填项；仅在总结里写“以后注意”不算修复。

## 额度与返工

- 用导演理解和完整故事板解决结构/表现形式，用全片有声动态分镜解决时长/阅读/转场，用15—20秒真实样片解决正式视觉和动作方向，用完整低清粗剪解决全片成片问题，最后才渲染母版；
- 样片阶段默认最多10次图像生成、2次Flow测试；未经样片批准不得批量生产；
- 单条片只设一个导演、一个时间线owner和最多一个技术/资产助手，不开启多个视觉方向并行竞赛；
- 连续两轮样片仍命中同一方向性否决，停止路线并回到导演简报，不靠继续堆素材硬顶；
- 修改局部只打开受影响镜头和锁定矩阵，不重新理解整条片；
- 机械检查交给脚本：文件、哈希、时长、帧率、字幕边界、空白容器、退出、音频漂移和交付一致性；
- AI只用于语义判断、画面创意、异常解释和用户真正需要权衡的地方；
- 发现消耗明显高于同长度同档位项目时，向牧之说明消耗在什么地方、是否值得继续；不自动叫停，也不静默烧额度。

## 每轮收尾

施工单只更新九项：当前Gate、完成项、批准项、锁定项、允许修改项、校验结果、可见交付、下一步、待牧之决定。不要把运行日志粘进去。
